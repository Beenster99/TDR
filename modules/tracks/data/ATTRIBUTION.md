# Track data attribution

`spielberg.json` was generated by `modules/tracks/tools/import_tumftm_track.py` from the
[TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database)
(Technical University of Munich, LGPL-3.0). Centre lines originate from
OpenStreetMap (ODbL) and track widths from satellite imagery.

The layout is the real-world circuit at Spielberg, Austria. The game uses the
place name only, not the circuit's commercial/sponsor name.
